# Machine Learning Portfolio

Welcome! This repository serves as a collection of machine learning projects spanning both traditional ML and Generative AI.

## Objectives
This repository is designed to explore, implement, and evaluate machine learning systems across a variety of real-world applications. Projects emphasize:

- Data preprocessing and feature engineering
- Model development and optimization
- Performance evaluation and interpretability
- Reproducible experimentation
- Deployment-ready workflows

## Project Categories

### Traditional Machine Learning
Projects focused on predictive modeling tasks such as:

- Classification
- Regression
- Clustering
- Dimensionality Reduction
- Time Series Forecasting

Common algorithms include:

- Linear & Logistic Regression
- Decision Trees
- Random Forests
- Gradient Boosting (XGBoost, LightGBM)
- Support Vector Machines
- Neural Networks

### Generative AI
Projects focused on creating intelligent systems capable of generating content, including:

- Large Language Models (LLMs)
- Retrieval-Augmented Generation (RAG)
- AI Agents
- Text Generation
- Image Generation
- Prompt Engineering
- Fine-Tuning and Evaluation

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / PyTorch
- Hugging Face Transformers
- LangChain / LlamaIndex
- OpenAI APIs
